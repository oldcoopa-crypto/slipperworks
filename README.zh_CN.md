# 库巴的拖鞋工坊

Coopa 卡上的物理合成经营游戏:库巴在工坊里给全家做拖鞋 —— 丢鞋材、合成大鞋、收进背包、卖出换原料,再用原料买高级鞋材扩大生产。平时慢慢攒,但富起来就险:桶里堆着值钱大鞋的时候,警戒线和桶容量都是真威胁 —— 翻一次桶,桶里和背包里的鞋全洒掉。工坊现场(桶里的鞋、排队的鞋、锤子)随存档保存,回标题、关游戏再回来都接着干;里程碑星星一旦点亮永久保留,新的工坊也清不掉。

- **合成大鞋**:▲▼ 挪吊臂,● 丢下;两只同级的一碰就合成上一级 —— 鞋垫一路合到奶奶的传说武器「回旋拖鞋」,中间每一级都是全家人的鞋(猫的小布拖、大黄的爪爪拖、爸爸的牛皮拖……)
- **收进背包**:长按 ▼ 把成品(小布拖及以上)收进背包;留在桶里继续合更值钱,早点收走更安全 —— 挣扎就在这一念之间
- **卖出换原料**:背包页 ● 卖 1 只、长按 ● 卖光一行;价目按 ×2.5 递增(鞋垫 1 → 回旋拖鞋 4000)
- **鞋种升级**:背包里选中一种鞋长按 ▼,花原料给它升级(最高 3 级,每级卖价 +30%,满级翻倍)—— 经常卖的鞋先升,越卖越值钱
- **鞋材铺**:功能菜单里选「鞋材铺」,买小布拖/大黄拖/库巴拖**直接换到手里**——绳子上立刻就是刚买的,手里的原鞋材自动排到队尾不丢不亏;「下一只」预览永远显示队首;或补大锤。还有**拖鞋篮升级**(最高 5 级,价 50/150/500/1200):篮子越大越宽,能合成的档位也越高 —— Lv1 只能合到库巴拖(两只库巴拖相遇不合),Lv5 解锁全部十级;铺子里 ● 买入,最底行「去背包 / 关铺子」
- **翻桶(失败)**:鞋堆压着警戒线累计 1 秒(颤动不清零,离开线就暂停)就翻桶啦 —— 桶里和背包里的拖鞋全洒掉,原料、累计收入和里程碑保留;警戒线一冒头就闪红,越危险闪得越急,压线时屏幕上出现倒计时大数字。桶里最多装 26 只鞋材,装满就不能再丢,收鞋或合成腾出地方才能继续
- **大锤压桶**:堆冒过警戒线后 ● 变成压桶锤,把堆敲实下去(散渣塔只能靠它救);铺子里 10 原料一把
- **连锁**:400ms 内连续合成会连锁,连锁越高奖励原料越多;两只回旋拖鞋相融是大合体 —— **拖鞋雨**:奶奶喊一嗓子「拖鞋会拐弯!」,奖金 1000 原料,再从天上哗啦啦落下 20~30 只库巴拖到爷爷拖级别的大鞋 —— 雨里的鞋还能继续合成(两只爷爷拖就是一只奶奶拖),雨停前不判翻桶
- **辣度三档**:标题页选中「辣度」● 换档 —— 微辣桶更宽卖价 +130%,特辣桶更窄卖价 ×80%
- **剧情与新手教程**:「新的工坊」开场演一段「练成躲拖鞋 → 奶奶批准开店」的对话剧(逐字对话框 + 奶奶/库巴配音);进工坊后奶奶手把手教丢鞋、合成,等合出第一双成品鞋才教收鞋,收完鞋再教开菜单;达成里程碑、升级篮子、触发拖鞋雨都有奶奶的夸奖台词。**八颗星全部点亮后**,再进工坊会演一段收尾剧情:奶奶感动之余把奶奶拖传给库巴,库巴道谢 —— 这双奶奶拖真的会放进你的背包
- **跨游戏联动**:《库巴大冒险》通关的老兵,标题页亮徽章
- **里程碑 8 个(=商城星星,永久保留)**:开张卖鞋、合出爸爸拖、背包里珍藏一只奶奶拖、合出金拖鞋、合出回旋拖鞋、篮子升满 5 级、任一鞋种升满 3 级、两只回旋拖鞋合成拖鞋雨。游戏里另有成就播报:大锤救场、收入过万等

## 文件夹里有什么

| 文件 | 是什么 |
|---|---|
| `coopa.toml` | 游戏的「身份证」:id、名字、版本、SDK 版本、入口、里程碑 |
| `slipperworks_texts.h` | 屏幕上的全部文字(字库从这里收集字) |
| `src/slipperworks_art.*` | 原创字符画:十级拖鞋链(10→44px 渐变尺寸)、原料线卷、大锤、闪光,共用 39 色调色板 |
| `src/slipperworks_logic.*` | 纯玩法:verlet 物理桶、合成、连锁、收鞋、价格表、出材序列 —— 不碰屏幕不碰 NVS |
| `src/slipperworks_save.*` | 存档布局(176 字节,老档自动迁移)、校验、里程碑推导 |
| `src/slipperworks_ui.*` | 全部画面:标题、工坊、鞋材铺浮层、背包 |
| `src/slipperworks_app.c` | 卡的外壳通过 `kit_app_t` 表叫你的游戏 |
| `tools/artcheck.py` | 校验字符画:行数、行宽、调色板字符 |
| `tools/simtest.sh` | 重建 ASan 模拟器并跑按键脚本(无头) |
| `tools/devlink.py` | USB 联机小工具:给真机截屏 / 模拟按键 |

## 玩法对应

| 画面 | 按键 |
|---|---|
| 标题页 | ▲▼ 选、● 确定(进工坊 / 背包 / 辣度 / 回菜单) |
| 工坊 | ▲▼ 挪吊臂、● 点按丢鞋;堆冒警戒线后 ● = 压桶锤 |
| 工坊(长按) | 长按 ▼ 收鞋入背包;长按 ● 打开**功能菜单**(物理暂停;开菜单前丢出的那只鞋照常算数) |
| 功能菜单 | 继续做工 / 鞋材铺 / 背包 / 收鞋入背包 / 大锤敲一下 / 回标题 / 回菜单 |
| 鞋材铺 | ▲▼ 选、● 买入;最底两行「去背包 / 关铺子」(关铺子回到功能菜单) |
| 失败页 | ● 再开一桶(洒掉的鞋找不回来,原料还在) |
| 背包 | ▲▼ 选拖鞋行、● 卖 1 只、长按 ● 卖光一行、长按 ▼ 升级鞋种;最后一行「回到功能界面」 |

## 开发

Codespaces 或本地 Dev Containers 里:`coopa run` 试玩(↑↓ 空格 = ▲▼●,按住 = 长按;`--seed` 复现同一串鞋材)、`coopa check` 跑和商店一样的检查。物理与经济参数集中在 `slipperworks_logic.c` 顶部的宏和 `slipperworks_sell_price` / `slipperworks_shop_*` 数据表,调平衡不用动逻辑。
